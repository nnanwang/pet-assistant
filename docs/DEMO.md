# Demo recording script (about 2–3 minutes)

Use a fictional pet and images you are authorized to share. Start `npm run dev`, open http://localhost:8082 and verify Connection settings. Do not show .env, API keys, or unrelated desktop content in a recording.

| Time | Screen and action | Narration |
| --- | --- | --- |
| 0:00–0:15 | Home; show the three care cards | “Pet Health Assistant organizes symptoms and visible behavior into a caring next step.” |
| 0:15–0:45 | Health; enter name, species, age/weight units and observations | “A shared profile includes age, size, food restrictions, and recent changes. Required inputs are checked before analysis.” |
| 0:45–1:05 | Submit; show result | “The app uses a server-side AI integration. Results include possible causes, urgency, red flags, practical next steps, and general diet guidance.” |
| 1:05–1:35 | Behavior; add 1 photo, remove/re-add one, add context | “Photos are previewed, numbered, compressed and sent with the pet’s symptoms. The result explains visible evidence and marks confidence as an AI estimate.” |
| 1:35–2:00 | Emotion; describe behavior directly and analyze | “Emotion works on its own with photos or text. A profile is optional. It suggests possible emotions and calming steps. Existing assessments can also be combined separately.” |
| 2:00–2:20 | Home; view saved assessment and connection/privacy settings | “Profiles and history are local. Raw photos are not saved. Owners can share an assessment with a veterinarian or clear local data.” |
| 2:20–2:35 | Health; select urgent sign and show warning | “Urgent signs display emergency guidance immediately, without waiting for AI. This app does not diagnose or prescribe medication.” |

Wait for real results; do not substitute sample output without labeling it. Real inference requires a valid provider key and quota. A recording should include no real medical/personal data. This file is a recording script, not evidence that a video or physical-device test has been completed.
